# Color palette attribution

The bundled paper color palettes use color values from these open-source projects:

| Project | Official color data | License |
| --- | --- | --- |
| [Open Color](https://yeun.github.io/open-color/) | [open-color.json](https://github.com/yeun/open-color/blob/master/open-color.json) | [MIT](https://github.com/yeun/open-color/blob/master/LICENSE) |
| [Nord](https://www.nordtheme.com/) | [nord.css](https://github.com/nordtheme/nord/blob/develop/src/nord.css) | [MIT](https://github.com/nordtheme/nord/blob/develop/license) |
| [Catppuccin](https://github.com/catppuccin/catppuccin) | [palette.json](https://github.com/catppuccin/palette/blob/main/palette.json) | [MIT](https://github.com/catppuccin/palette/blob/main/LICENSE) |

Colors were checked against these sources on 2026-09-19. The Chinese names and
combinations for paper cards are this plugin's own selections, not official
palette names or endorsements. Catppuccin selections use the Latte, Frappé,
Macchiato and Mocha flavors. All values are bundled locally; selecting a palette
does not contact these websites or send vault contents. Source links open only
when selected by the user.
