- 同一图注同时包含复合词连字符和跨行断字时，正确核对两种排版。
- 图注内的星形、圆点等嵌入图形不再误当成 PDF 缺失文字；严格核对文字和符号所在空白，保留中文图注中的符号，并记录整理过程。
- Skill 明确区分原文文字层证据与原页图形，缓存草稿重试也会使用更新后的规则。
- 保留文字、数值、数学运算符、页码检查；失败任务可复用缓存，不必重新生成全文。

安装：下载 `obsidian-mypaper-plugin-1.1.1.zip`，用其中的插件文件更新笔记库 `.obsidian/plugins/obsidian-mypaper-plugin/`。保留自己的 data.json、任务记录与论文附件。Skill 随插件更新，无需单独安装。
