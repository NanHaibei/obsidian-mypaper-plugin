支持论文原本未编号、没有独立图注的原图和原表，修复合法资料被阻止写入的问题。

- 原文未编号图表使用 PDF 页码和条目定位，保留原图，不伪造论文编号。
- 没有独立图注时，以该页原文片段定位，明确标注“原文无独立图注/表注；以下为 AI 说明”；不把相邻正文冒充原图注。
- 模型返回未完成时也保留最新草稿与缺失项，继续严格检查章节、原图、页码与来源证据。
- 长错误信息在列表显示摘要，更多操作可查看完整原因。
- 兼容此前编号图表的缓存结果，阅读 Skill 随插件一起更新。

安装：下载 `obsidian-mypaper-plugin-1.1.2.zip`，将新版三个插件文件覆盖到笔记库 `.obsidian/plugins/obsidian-mypaper-plugin/`，重新启用插件。保留自己的 data.json、任务记录与论文附件；无需另装 Skill。
